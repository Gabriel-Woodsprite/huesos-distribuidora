# huesos-distribuidora

<h1>Cómo usar Node & Gulp</h1>
<h2>Instalar dependencias</h2>

```cmd
npm install
```

<h2>Ejecutar gulp</h2>
Una vez instalada cada dependencia (node_modules). El siguiente comando se activa en una terminal que escuchará por los cambios en src:

```cmd
npm run dev
```

Para detener la ejecución de este script basta con hacer ctrl+C sobre la terminal

> [!TIP] Node_modules y el push de git
> Para mantener un repositorio ligero, se recomienda eliminar la carpeta de node_modules antes de hacer cualquier actualización en el repositorio (git add, git commit o git push)
